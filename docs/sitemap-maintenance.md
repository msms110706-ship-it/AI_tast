# Sitemap 변경일 관리

원본은 `app/sitemap.js`이며 `npm run build`로 XML과 배포 복사본을 생성한다. dist 파일을 직접 편집하지 않는다.

## 현재 날짜의 근거

| 공개 canonical 경로 | lastmod | 근거 |
| --- | --- | --- |
| / | 2026-10-05 | 현재 보완 작업에서 학습 코치 호출 시도 표시와 오류 시 차감 안내 등 홈 내용을 수정 |
| /about, /guides 및 8개 가이드 상세 페이지 | 2026-09-24 | 커밋 3acc1c4에서 사이트명·공통 헤더/푸터·검색 메타데이터 변경. 소개 및 가이드 목록 본문도 변경 |
| /privacy, /terms | 2026-09-24 | 같은 사이트명 변경 및 기존 미커밋 코치·결제 준비 안내 수정. 수정 파일 기록과 본문 적용일이 2026-09-24로 일치 |

가이드 상세 본문의 학습 내용 자체가 9월 24일에 수정됐다는 뜻은 아니다. 이 날짜는 공통 사이트명과 해당 페이지의 메타데이터 변경을 반영한다. 홈 이외의 콘텐츠는 10월 5일에 수정하지 않았다.

## 갱신 원칙

- 실제 공개 페이지 내용이나 중요한 메타데이터를 수정할 때 해당 경로의 날짜만 명시적으로 갱신한다.
- 현재 시각, 빌드 시각, 파일 mtime, 전체 저장소의 최근 커밋 날짜로 자동 계산하지 않는다.
- 빌드, CSS 정렬 보정, 서버 코드 수정만으로 모든 페이지의 날짜를 올리지 않는다.
- 새 페이지는 공개 canonical URL과 날짜를 추가하고 삭제·비공개 전환 시 목록에서 제외한다.
- 생성된 XML의 URL 목록을 정적 HTML의 index 가능한 canonical URL 전체와 대조한다. API, 404, 중복 URL, 쿼리·fragment URL은 포함하지 않는다.

현재 Next 설정의 trailingSlash에 맞춰 sitemap loc도 끝 슬래시를 포함한다. 생성 HTML의 canonical과 문자열 단위로 일치시킨다.
